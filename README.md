# KURO NEKO 

## Online Japanese Restaurant Ordering System

KURO NEKO is a web-based Japanese restaurant ordering system that allows customers to browse the restaurant menu, add dishes to their cart, place orders, make payments, and view their order status.

The system also provides an administrator interface for managing menu items and monitoring customer orders.

---

## Features

### Client

Customers can:

- Create a new account
- Sign in to their account
- Browse the restaurant menu
- Filter dishes by category
- View dish details
- Add dishes to the cart
- Update item quantities
- Remove items from the cart
- Choose delivery or pickup
- Enter order information
- Make a payment
- View order confirmation
- View order history
- View order status
- Manage their profile
- Send contact messages

### Administrator

Administrators can:

- Sign in to the administrator account
- Access the admin dashboard
- View customer orders
- Update order status
- Manage menu items
- Add new dishes
- Edit existing dishes
- Remove dishes
- Update dish availability
- Manage their profile

---

## User Roles

The system consists of two main actors:

| Role | Description |
|---|---|
| Client | Browses the menu, manages their cart, places orders, and views order status. |
| Administrator | Manages menu items and monitors and updates customer orders. |
